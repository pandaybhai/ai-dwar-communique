# AiDwar — marketing site

Public marketing site for [AiDwar](https://aidwar.in), an AI-powered WhatsApp marketing and AI-agent platform for growing businesses, built on the official WhatsApp Business Platform (Cloud API). Home, privacy policy and terms pages. React + Vite + Tailwind, built with Lovable.

The product itself is private; how it is built is documented in [aidwar-architecture](https://github.com/pandaybhai/aidwar-architecture).

AiDwar is a product of Meezoy Ventures Private Limited, Hyderabad. WhatsApp is a trademark of Meta Platforms, Inc.
